\section{Applying uncertainty to qualitative indicators}
\label{sec:qualitative_indicators_uncertanty}
As presented in section \ref{sec:qi}, the author prepared an informed starting point for all \glspl{qi} included in the analysis. The starting point determines an order of the alternatives and a linear value function, either increasing or decreasing, assuming all points equally spaced. Hypothetical worst and hypothetical best points are included to give more flexibility during value function design. A graphic tool developed in python was used to support the elicitation session. Experts were first presented with the author's starting point, to which they are then asked to provide feedback and modify the order as they see fit (Figure \ref{fig:qi_order}). Then, the value function can be adjusted to increase or decrease the difference between alternatives (Figure \ref{fig:qi_value}).
