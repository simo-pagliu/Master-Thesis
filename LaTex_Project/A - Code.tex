All computational materials supporting this research are available in the following GitHub repository:
\url{https://github.com/simo-pagliu/Master-Thesis/}

The repository contains:
\begin{itemize}
    \item \textbf{Reactor Selection and Analysis}: Implementing the methodology described in Section \ref{sec:selection_reactors} (Location: \nolinkurl{01 - Attributes Definition/Reactors Data/Reactor Analysis.ipynb})
    \item \textbf{Energy Data Analysis}: Supporting the country selection process outlined in Section \ref{sec:country_selection} as well as the definition of indicators detailed in Sections \ref{sec:red_elect_price} and \ref{sec:ghg_red} (Location: \texttt{01\ -\ Attributes\ Definition/Electricity\ Data/Electricity\ Market\ Analysis.ipynb})
    \item \textbf{Indicator Database}: List of 35 possible indicators that were considered for the analysis as explained in Section \ref{sec:brainstorming_indicators}, a python script to help navigate the csv file is also provided (Location: \texttt{01\ -\ Attributes\ Definition/Attribute\_DB.csv})
    \item \textbf{Indicators}: Spreadsheet containing the final list of indicators, previous revisions and intermediate caluclations referenced in Section \ref{sec:brainstorming_indicators} (Location: \texttt{01\ -\ Attributes\ Definition/Indicators.ods})
    \item \textbf{Digital Elicitation Tools}: Python scripts are availble at \nolinkurl{02 - Value Functions/main.py} for mid-value splitting and \nolinkurl{02 - Value Functions/qualitative_elicitation.py} for qualitative indicators. Weight elicitation utility is \nolinkurl{03 - Weighting/main.py}. These scripts are far from being user-friendly and are \textbf{provided as proofs of concept only}. More refined tools will be availble in the near future.
    \item \textbf{Complete Results}: All the plots generated are available in the \nolinkurl{Complete Results} folder, including those not reported in the thesis for brevity.
\end{itemize}
