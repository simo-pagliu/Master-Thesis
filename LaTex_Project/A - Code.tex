All computational materials supporting this research are available in the following GitHub repository:
\url{https://github.com/simo-pagliu/Master-Thesis/}

The repository contains:
\begin{itemize}
    \item \textbf{Reactor Selection and Analysis}: Implementing the methodology described in Section \ref{sec:selection_reactors} (Location: \texttt{01\ -\ Attributes\ Definition/Reactors\ Data/Reactor\ Analysis.ipynb})
    \item \textbf{Energy Data Analysis}: Supporting the country selection process outlined in Section \ref{sec:country_selection} as well as the definition of indicators detailed in Sections \ref{sec:red_elect_price} and \ref{sec:ghg_red} (Location: \texttt{01\ -\ Attributes\ Definition/Electricity\ Data/Electricity\ Market\ Analysis.ipynb})
    \item \textbf{Indicator Database}: List of 35 possible indicators that were considered for the analysis as explained in Section \ref{sec:brainstorming_indicators}, a python script to help navigate the csv file is also provided (Location: \texttt{01\ -\ Attributes\ Definition/Attribute\_DB.csv})
    \item \textbf{Indicators}: Spreadsheet containing the final list of indicators, previous revisions and intermediate caluclations referenced in Section \ref{sec:risk} (Location: \texttt{01\ -\ Attributes\ Definition/Indicators.ods})
\end{itemize}
