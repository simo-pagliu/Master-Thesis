\section{Value Functions}
\label{sec:value_functions}
The elicitation of value functions is based on the mid-value splitting technnique, described in section \ref{sec:mavt_presentation}. Given the higher cognitive demand of this task and the time required only a smaller set of experts was consulted (\textcolor{red}{PLACEHOLDER} in total). A first elicitation was carried out with a very available and patient expert in teh field of risk assesment for nuclear, this sessions was kept true to the mid-value splitting technique but the time required was significant, enough to not be acceptable for most experts (around 2 hours). For this reason the subsequent sessions were carried out with a similar approach to that used for \glspl{qi} (section \ref{sec:qualitative_indicators_uncertanty}), where the expert is first presented with an initial value function (the result of the first elicitation) and is then asked to provide feedback and modify it as they see fit. This approach noticably sped up the process, it must be noted regardless that this method, closer to a direct elicitation process, may introduce some bias as the starting point may influence the expert judgement. For this process another graphical tool was developed in python, some screenshots of the interface are presented in Figure \ref{fig:value_function_elicitation}. Some example of value functions that different significantly among experts are presented in figure \ref{fig:value_function_examples}.
