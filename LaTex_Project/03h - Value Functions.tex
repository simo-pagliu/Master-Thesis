\section{Value Functions}
\label{sec:value_functions}
The mid-value splitting technique, described in section \ref{sec:mavt_presentation}, is a well-established elicitation method for constructing value functions. However, its application is extremely time-consuming and cognitively demanding for experts. To address these challenges, this study carried out a \textit{first elicitation} adhering to the mid-value splitting technique to establish an initial set of value functions.

Subsequent elicitations employed a similar approach to that used for \glspl{qi} (section \ref{sec:qualitative_indicators_uncertanty}), where the expert is first presented with an initial value function (the result of the first elicitation) and is then asked to provide feedback and modify it as they see fit. This approach noticeably sped up the process, but is also likely to have introduced some anchoring bias. For this process, another graphical tool was developed in python, screenshots of the interface are presented in Figure \ref{fig:value_function_elicitation}. Some example of value functions that different significantly among experts are presented in figure \ref{fig:value_function_examples}.
